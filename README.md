# Nostradamus

Suivi des variations de cotes foot avant match (Pinnacle et Winamax, marché 1N2) sur 8 compétitions.
Un outil d'aide à la décision : il observe le marché, il ne garantit aucun gain.

- **Où en est le projet, comment ça marche, ce qui reste à faire : [NOTES.md](NOTES.md)**
- Le collecteur tourne tout seul (GitHub Actions) et range ses relevés dans `data/`.
- Tests : `python3 -m unittest discover tests`
